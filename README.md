# README Badges

**262 ready-made badges** in one style, each available in two variants:

- **With icon**: the real technology logo (currently 250 badges have one).
- **With letters**: a monogram of one or two letters (available for all 262).

These are plain SVG files: they live in the repository, don't depend on shields.io, and never break because of "unknown icons".

## How to use

1. **The easiest way:** open the [gallery page](https://bread11yt.github.io/badges/), pick a variant (with icons or with letters), click a badge, and the code is copied to your clipboard. Paste it into your README.
2. **Via this README:** browse the badges in the tables below and copy a category's code (each category has collapsible code blocks: one badge per line, with a copy button in the corner of the block). Just delete any extra lines after pasting.
3. **Directly:** a badge link looks like `https://raw.githubusercontent.com/Bread11YT/badges/main/badges/VARIANT/CATEGORY/NAME.svg`, where VARIANT is `with-icon` or `letters`.

To center the badges in your profile, wrap them in:

```html
<div align="center">

  <!-- paste your badges here -->

</div>
```

To make a badge a link, wrap it like this: `[![Python](badge-link)](https://python.org)`.

## Icons

If the `icons/` folder contains a file with the same name as a badge (for example, `icons/python.svg` for the `python` badge), an icon version is generated for it. The letters version is always generated.

To add or replace an icon: put a single-color SVG (preferably square, viewBox 24×24) at `icons/NAME.svg` and run `python build.py`. You don't need to set a color, the generator colors the icon itself. You can get logos from [simpleicons.org](https://simpleicons.org). Sources and licenses: `icons/NOTICE.md`.

## Add your own badge

All you need is Python 3:

```bash
python build.py add "Bun" E8B84A Bn "Web"
```

Parameters: name, color (HEX without `#`), 1-2 letters for the monogram, category and (for a new category) a folder name in Latin letters. The script creates the SVG and updates the README and the gallery page.

## Configuration

At the top of `badges.json` you'll find `owner`, `repo` and `branch`. If you named the repository differently or have a different username, change them and run `python build.py`: all links in the README and on the page will be updated.

The gallery page runs on GitHub Pages: *Settings → Pages → Deploy from a branch → `main` / `(root)`*.

Every badge is built in all preset colors: `badges/colors/COLOR/VARIANT/category/name.svg`. On the gallery page click "Custom" and a color circle, and the code will use the link to the matching file. Any other color can be picked with the color picker: the page draws the badge, you download it with the "↓ SVG" button and put it in `badges/custom/` (`build.py` doesn't touch that folder).
